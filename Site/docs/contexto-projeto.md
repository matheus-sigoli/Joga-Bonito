# Contexto do Projeto — PIM IV | Joga Bonito (Artigos Esportivos)

## Empresa & Marca
- **Nome**: Joga Bonito
- **Slogan / Tagline**: Artigos Esportivos e Camisas de Futebol
- **Segmento**: Moda esportiva, mantos de futebol e artigos de performance
- **Identidade Visual**: Verde (#0E552A) e Amarelo (#FCCA0F)
- **Modelo de Negócio**: E-commerce B2C e App Mobile
- **Público-alvo**: Apaixonados por futebol, colecionadores de camisas históricas retrô, praticantes de esporte e torcedores.

## Fase Atual
- **PIM III**: ✅ Concluído (1º semestre 2026)
- **PIM IV**: 🚀 Em andamento (2º semestre 2026) — Transição e Rebranding concluídos para Joga Bonito.

## Stack Tecnológica
- **Frontend Web**: HTML5, CSS3 Vanilla com Glassmorphism Esportivo, JavaScript Vanilla
- **Backend API**: .NET 8 (C#) — Arquitetura em Camadas
- **Banco de Dados**: SQL Server Express
- **Mobile**: Flutter (Dart)
- **Containers**: Docker + Docker Compose
- **CI/CD**: GitHub Actions
- **Autenticação**: JWT + BCrypt

## Estrutura de Pastas do Site
- `Site/HTML/` — Páginas Web (inicial, catalogo, Produtos, carrinho, pedidos, login, cadastro, privacidade, admin)
- `Site/CSS/` — Estilos customizados (verde #0E552A e amarelo #FCCA0F)
- `Site/Javascript/` — Lógica do e-commerce, carrinho e autenticação
- `Site/IMG/` — Logotipos oficiais (LOGO.png, LOGO 2.png, LOGO 3.png) e imagens do catálogo
- `Site/backend/` — API REST em .NET 8
- `Site/banco/` — Scripts SQL Server (schema.sql e seed.sql)
- `ABNT/` — Documentação acadêmica UNIP
- `Backlog/` — Product Backlog e Sprint Planning

## Macro-Categorias do Catálogo
1. **Temporada 2026**: Mantos atuais dos principais clubes e seleções para o ano vigente.
2. **Camisas Retrô**: Clássicos históricos de copas, finais épicas e craques memoráveis.
3. **Chuteiras**: Campo, Society e Futsal.
